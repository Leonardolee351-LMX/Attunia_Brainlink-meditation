# Attunia Pitch — 9 页口述稿（可粘贴进 Kimi Slides / Gamma）

**赛道：** Soft Healthcare（生命健康 / 软医疗）  
**产品：** Attunia · 编排 Agent **Tuno**  
**一句话：** 对准 Work–Life 真空期与工位上的走神/超负荷，用脑电调律 + 短训，不做诊断与处方。  
**参考：** `docs/agent-lab/PROGRESS-BRIEF.md`；Kimi 分享（华为 WATCH 5 · HRV ↔ 自主神经）https://www.kimi.com/share/1a0749f8-0082-84e1-8000-0000db17f12d  

生成提示（丢给 Kimi Slides）：`Pitch deck, 9 slides, dark editorial, few words, Soft Healthcare, no stock meditation photos, Chinese titles + one English subtitle each.`

---

## 1. Cover
**标题：** Attunia  
**副标：** Soft Healthcare · Work–Life 调律  
**台词：** 不是帮你睡得更香的 App。是帮你在「工位 ↔ 生活」之间，把没收尾的状态接住。

## 2. Hook · 切不掉
**标题：** 电脑合上了，脑子没有  
**台词：** 晚上七点、早上九点、连续开会之后——人已经换场景，神经系统还停在上一场。痛点不是「不会睡」，是**切不掉 / 启不来 / 扛过头**。

## 3. Problem · 红海 vs 空白
**标题：** 睡前很挤，工位边很空  
**台词：** Calm / Headspace / Muse 主攻枕头边。白领真正缺的是 **6–9 点与会后空档** 的短时调节，以及工位上的回笼与卸压。

## 4. Who · Soft Healthcare 边界
**标题：** 调节，不是诊疗  
**台词：** 报名 Soft Healthcare：日常身心状态调节与福祉。显著免责 + 危机转介。不宣称诊断、处方或医疗器械。

## 5. Science · 脑 +（可选）身
**标题：** 看见「高挡位还在不在」  
**左栏 · 已做：** NeuroBand 三通道（唤醒 / 专注 / 平静）驱动推荐与训练反馈。  
**右栏 · 科学对照（Kimi / 手表 HRV）：**  
- 副交感占优 → HRV 升 → 更易恢复  
- 交感占优 → HRV 降 → 紧张 / 应激  
**注意上台口径：** 华为 WATCH 5 提供综合 HRV，**没有单独「交感神经指数」**；静止/睡眠趋势比单点更有意义。Attunia **本轮以脑电为主**；HRV 是同赛道可互补的身体侧信号，不假装我们已经接上手表 SDK。

## 6. Solution · 三刻介入
**标题：** 真空期 · 回笼 · 卸压  
1. 上下班 / 会后真空期 — 下工仪式、会后留白  
2. 工位走神 — 摸鱼回笼、开工前奏  
3. 超负荷 — 超载减负四步路径  
**机制：** 校准基线 → 状态命名 → 场景短训 → Tuno 对话；需要时 Multi-Agent **只拼目录内疗法**（不即兴、不生图作曲）。

## 7. Demo · 60 秒路径
**标题：** 看得见、听得见、练得完  
**流程：** Attunia 开屏 → 戴头环校准 → 六景推荐 → Session（脑电 × 画面）→ 需要时 Tuno / Friends 会诊。  
**贴图位：** 开屏 / 六景 / 训练播放器 / 会诊各一张。

## 8. Moat · 别吹大模型
**标题：** 难复制的是「节律闭环」  
可讲：WLB 时刻设计 · 脑电闭环 · 目录编排的多专家 · 记忆降权避免同一疗法死循环 · Soft Healthcare 合规。  
少讲：通用 LLM、头环硬件本身、未接入手表的 HRV。

## 9. Ask · 验证与下一步
**标题：** 我们要什么  
- 赛道名次 / Soft Healthcare 评委认可  
- 试点：白领碎片场景真机演示  
- 下一步：主动提醒严控误报 · 视效声景沉浸 ·（可选）身体侧 HRV 互补通道调研  
**验证口：** 无记忆 vs 有记忆 · 无脑电 vs 有脑电 · 无 LLM vs 有 LLM（产品性，不是堆模型）。
