# 六景音乐提示词（v4）

训练咨询 · 2026-09-05 · 供 **F-14** / 人工出曲入库  
真相源：同目录 `music-prompts.json`  
用法：MiniMax Audio / Suno / Udio 开 **Instrumental（纯器乐）**，粘贴下方「英文 Prompt」或「中文 Prompt」；Negative 有则填 Exclude。

**不是**程序化音效床；**是**可循环的软氛围器乐冥想床轨。始终比引导词安静。勿在会诊运行时现作曲。

---

## 共用 Negative

```
vocals, lyrics, choir, drums, trap hats, EDM drop, pop chorus, lo-fi beat, trailer brass, epic climax, horror drone, sirens, alarms, cafe chatter, sad ballad heroics
```

---

## 1. clock-in · 开工前奏

- **迁移：** 唤醒 keep · 专注 up · 平静 up  
- **一句话：** 黄油晨光，注意拢成一点  

**中文 Prompt**

```
纯器乐冥想床轨，上班前「开工前奏」。黄油晨光、轻轻清醒：把散落的注意力柔软地拢成一个点。温暖的 Rhodes 和弦与缓慢铺底垫音，D 大调或相近暖调，安静粉噪空气垫在下面，远处偶尔一两声麻雀只作色彩。无人声、无歌词、无鼓点、无 EDM、无 lo-fi 鼓机循环、无闹钟感。不写成流行歌结构，不要副歌高潮。约三分钟，结尾柔软可循环，音量需能垫在女声引导词下面。整体气质：友善、清晰、不困、不压迫。
```

**English Prompt**

```
Instrumental meditation bed for morning desk warm-up (clock-in). Soft warm ambient: gentle Rhodes chords and slow harmonic pads in D major, quiet pink-noise air underneath, distant soft birds as color only. Kindly awake, unhurried focus gathering into one soft point — clear, not sleepy, not pressured. No vocals, no lyrics, no drums, no EDM, no lo-fi beat loop, no alarm tone, no pop chorus. About 3 minutes, loop-friendly soft ending, always quieter than spoken guidance.
```

**本景 Negative：** `alarm, cafe chatter, lo-fi drums, metronome march, piano ballad climax`

## 2. post-meet · 会后留白

- **迁移：** 唤醒 down · 专注 keep · 平静 up  
- **一句话：** 走廊变空，呼气更长  

**中文 Prompt**

```
纯器乐冥想床轨，会后留白。身体还带着一点热，声场从略密慢慢变空、变软，像走廊一点一点空出来；呼气感比吸气更长。稀疏的钢琴点音与低暖垫音，鼠尾草绿的安静空气。无人声、无鼓、无电梯叮、无消息提示音、无大提琴英雄独奏、无悬疑弦乐、无电影配乐高潮。不要流行副歌。约三分钟，可循环，始终让路给引导词。气质：释放、降温、留白、友善。
```

**English Prompt**

```
Instrumental cool-down bed after a meeting (post-meet). Soft ambient with sparse piano notes and low warm pad; ISO-style: slightly denser midrange at first, then gradually empties. Sage-green calm air, long-exhale feeling. No vocals, no drums, no elevator ding, no notification pings, no suspense strings, no cello heroics, no film-score climax, no pop chorus. About 3 minutes, loopable, duck under spoken guidance. Mood: release, cooling, blank and kind.
```

**本景 Negative：** `elevator ding, notifications, cello solo heroics, suspense strings, cinematic trailer`

## 3. lunch-tide · 午憩航道

- **迁移：** 唤醒 down · 专注 keep · 平静 up  
- **一句话：** 午后浅水，还能回工位  

**中文 Prompt**

```
纯器乐冥想床轨，午憩航道。暖沙色午后，身体轻轻躺平一点，像漂在安静浅水上——不是夜里深度睡眠，听完还要能回工位。温暖低频潮汐感、持续的低五度长音、远处树叶轻擦；后半偶尔细碎高音亮点，像咖啡因还在路上。无人声、无鼓、无摇篮曲合唱、无暴雨墙、无颂钵连敲、无爵士咖啡馆钢琴。不要夜店低音。约三到四分半，可循环，垫在引导词下。气质：水平、柔软、午后安全。
```

**English Prompt**

```
Instrumental midday restore bed (lunch-tide). Warm sand-colored ambient, soft brown-noise tide, held low fifth drone, far leaves texture, tiny high sparkles later like caffeine still arriving. Horizontal rest without lullaby choir or night-deep sleep — still employable after. No vocals, no drums, no rainstorm wall, no singing-bowl barrage, no jazz cafe piano, no club bass. About 3–4.5 minutes, loopable under guidance. Mood: horizontal, soft restore, afternoon-safe.
```

**本景 Negative：** `lullaby choir, rainstorm, singing bowls, cafe jazz, club bass, sleep-app rain`

## 4. overload · 超载减负

- **迁移：** 唤醒 down · 专注 keep · 平静 up  
- **一句话：** 标签剥开，落回房间  

**中文 Prompt**

```
纯器乐冥想床轨，大脑超载减负。正面、柔和、安全。开头十几秒可以略挤（像太多标签叠在一起），然后一层层剥开，变成安静房间里清楚的近场：柔软垫音、开放五度、鼠尾草般地气与微光。无人声、无鼓、无白噪声墙、无故障毛刺、无警报、无恐怖低音、无悬疑钢琴跑动。不要电影紧张配乐。约三分钟，可循环，配合感官着陆。气质：安全落地、回到此时此地。
```

**English Prompt**

```
Instrumental grounding bed for cognitive overload. Positive soft landing: brief slightly crowded mid tones that peel into sparse ambient — soft fabric-like pads, open fifths, safe luminous sage room. Never horror drone or alarms. No vocals, no drums, no white-noise wall, no glitch, no suspense piano runs, no tense film underscore. About 3 minutes, loopable under 5-4-3-2-1 grounding. Mood: safe present-moment landing.
```

**本景 Negative：** `white noise wall, alarm, glitch, horror drone, suspense piano, thriller score`

## 5. drift-back · 摸鱼回笼

- **迁移：** 唤醒 keep · 专注 up · 平静 up  
- **一句话：** 允许漂，再软软回来  

**中文 Prompt**

```
纯器乐冥想床轨，摸鱼回笼。薄荷绿水面：允许漂一会儿，再软软滑回工作，友善、不评判。稀疏的五声音点水滴或极轻卡林巴式拨弦，中间要有留白；后半略微更有规律一点，像注意力自然回来——绝不要舞曲。无人声、无 trap 踩镲、无卡通泼水、无内疚小调钢琴说教、无流行副歌。约三分钟，可循环。气质：轻玩、柔软回来。
```

**English Prompt**

```
Instrumental return-from-daydream bed (drift-back). Mint water ambient: sparse pentatonic droplets and soft kalimba-like plucks that slowly become a gentle repeating figure — kind, playful, never scolding. Quiet gaps early; slightly more regular later as attention returns — never a dance groove. No vocals, no trap hats, no cartoon splash SFX, no guilty minor piano sermon, no pop chorus. About 3 minutes, loopable. Mood: kind soft play, gentle return.
```

**本景 Negative：** `trap hats, dance groove, cartoon splash, guilty piano sermon, pop hook`

## 6. clock-out · 下工仪式

- **迁移：** 唤醒 down · 专注 keep · 平静 up  
- **一句话：** 抽屉合上，室内灯暖  

**中文 Prompt**

```
纯器乐冥想床轨，下工仪式。墨色窗外，室内钨丝灯暖：把工作轻轻放下，回到生活身体——心理抽离，不是忧伤；今晚属于自己，但还不到入睡。软模拟垫音、闷吉他泛音；前段允许一次极轻的远处低木闷触（只一次），然后和谐更暖更慢。无人声、无悲伤钢琴叙事、无片尾英雄管弦、无纯雨循环助眠专辑、无办公提示音。约三到四分半，可循环。气质：下班边界、室内暖、回家的身体。
```

**English Prompt**

```
Instrumental clock-out ritual bed. Evening indoor warmth against dark window: soft analog pad, muted guitar harmonics, one distant low wood thud early then warmer harmony. Psychological detachment without melancholy — tonight is yours, not yet a sleep album. No vocals, no sad piano ballad, no heroic end-credits orchestra, no rain-only sleep loop, no office pings. About 3–4.5 minutes, loopable for commute or kitchen transition. Mood: off-duty warm boundary, home body.
```

**本景 Negative：** `sad piano ballad, heroic credits, rain-only sleep loop, office pings, trailer brass`
