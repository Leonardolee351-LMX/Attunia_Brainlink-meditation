## 现在差在哪

训练页已是深色播放器：`PlayerAura` 读三通道，阶段切换时 TTS 播一句 `phases[].instruction`。

三项关键训练仍像「播引导 + 通用光场」：

- 开工与会后都是同一套扩散圆环，下工是泛用光球，和封面几何（方块 / 下三角 / 抽屉横条）对不上。
- 呼吸是 `sin(t)` 随平静缩放，**不是** 4-4-4-4 或 4-7-8。
- 每个阶段只有一段长文，循环中没有短提示。
- 脑电只改光晕，不改「协议有没有被跟上」。

本切片把三件事写死：**画面母题、协议钟、分秒引导词**。脑电只改画面品质，不改节拍。

## 共用实现约定

`PlayerAura`（或后继组件）需要额外知道：`phaseIdx`、`phaseElapsedSec`、`planId`。不要只拿 `sceneId` 选调色板。

| 输入 | 用途 |
|------|------|
| 协议钟（墙上时间） | 画边、蓄光、泄光、抽屉开合相位 |
| focus | 几何齐不齐、边清不清 |
| calm | 场软不软、空不空、暖不暖 |
| arousal | 残留颗粒、微颤、未关清单 |

自适应口播最多每 45 秒一条，同一条每个阶段最多一次。只允许目录方法内的轻推（「带回这条边」「呼气再长一点」），不许改成别的疗法。

TTS：温婉女声、偏慢。短句、现在时、第二人称、不评判。不要报通道分数。

禁忌按目录执行：屏息不适改 4-6 或 4-0-8；下工不是睡前，不要做成 Nidra 全黑。

## 1. 开工前奏 · `clock-in` · `breath-box`

**6 分钟。** 唤醒 keep · 专注 up · 平静 up。

### 为什么是这个方法

箱式呼吸（4-4-4-4）给前额叶一条可预测的时间格子。等长四拍降低「下一步不确定」，比单纯深呼吸更像开工信号。16 秒一圈约 3.75 次/分，比日常呼吸慢，但四段停顿让注意力有东西可抓——这是专注热身，不是睡前下调。

目标不是把人压得很静，是把散掉的注意收回一个点，唤醒维持在可工作区。

### 画面

黄油方块画自己，一边一拍。背景是深羊皮纸，不是会议室照片。

| 拍 | 秒 | 画面 |
|----|----|------|
| 吸 | 0–4 | 顶边从左到右长出来 |
| 停 | 4–8 | 右边从上到下 |
| 呼 | 8–12 | 底边从右到左 |
| 停 | 12–16 | 左边从下到上；合拢后内心轻轻亮一下 |

**脑电改品质，不改这 16 秒。**

| 通道 | 低 | 高 |
|------|----|----|
| focus | 角对不齐，边发虚 | 直角咬合，边是利落细线 |
| calm | 内心空、场发干 | 内心黄油晕慢慢铺开 |
| arousal | 方块稳 | 轻微抖动、更偏琥珀；不要加速画边 |

少动：方块停在当前那条边的进度，不抖、不撒点。

手不用按屏幕（人可能在工位）。方块就是节拍器。不要做成呼吸之花的按压。

### 训练怎么走

**0:00–1:00 坐姿校准**

口播（进段）：找一个能靠住的地方坐下。双脚平放。想象头顶有一根线轻轻向上提。看一眼你等下要做的事，然后把目光收回来。

| 秒 | 对人说 |
|----|--------|
| 20 | 双脚踩实。肩膀不用端着。 |
| 40 | 屏幕上会有一个正方形。你只跟着它的边走。 |

画面：方块以虚线预览一圈，不正式计拍。

**1:00–5:00 四方循环**

口播（进段）：吸气四拍——停四拍——呼气四拍——停四拍。像在空气中画一个正方形。注意力跑了，就带回正在长出来的那条边。

| 秒 | 对人说 |
|----|--------|
| 4 | 吸。 |
| 20 | 停。边还在。 |
| 36 | 呼。把气慢慢放完。 |
| 52 | 再停一下。下一条边会自己来。 |
| 之后 | 默认静音，交给方块。只在下面两条触发时说话。 |

自适应（各最多一次）：focus 连续 8 秒低于 40 →「注意力跑了，就带回这条边。」；arousal 连续 8 秒高于 75 →「边可以画慢一点，不必用力。」（视觉仍是 16 秒，只改语气。）

**5:00–6:00 定锚**

口播（进段）：最后一次四方呼吸。睁开眼之前，对自己说：接下来这段时间，只有这一件事。

| 秒 | 对人说 |
|----|--------|
| 40 | 方块可以放下了。你带着这个点，开始工作。 |

结束：方块完整停住，内心稳住，不散开。

### 前端怎么算做对

闭眼也能靠边的生长知道吸/停/呼/停。专注升高时角变齐，是可演示的。不是又一套圆环。

## 2. 会后留白 · `post-meet` · `breath-478`

**8 分钟。** 唤醒 down · 专注 keep · 平静 up。

### 为什么是这个方法

4-7-8 把刹车做在**加长呼气**上：呼气拉长，副交感更容易占上风。7 拍屏息让二氧化碳略升，很多人会觉得更「沉」。会后残留的是会议心率，不是没注意——所以专注只保持，不要求再升高。

音乐上的 ISO：先承认身上还热，再把热泄掉。画面上的「会议尘」就是这件事。

屏息不适：视觉改 4-0-8（吸 4、呼 8，中间不蓄），口播改「吸，然后把气慢慢放完」，不要硬念 7。

### 画面

薄荷下三角在泄空。会议尘是浅色碎点，只在呼气时往下走、变淡。

| 拍 | 秒 | 画面 |
|----|----|------|
| 吸 | 0–4 | 光在顶点聚起来 |
| 停 | 4–11 | 光停在三角里，微微颤，不往外涨 |
| 呼 | 11–19 | 光沿三角往下泄；尘点跟着落、散 |

| 通道 | 低 | 高 |
|------|----|----|
| arousal | 尘很少 | 尘密（会刚散场） |
| calm | 泄不干净，场发闷 | 泄完后场空、偏薄荷 |
| focus | 泄的轨迹发飘 | 轨迹还在，不要求很尖 |

少动：三角静止，尘不飞。

### 训练怎么走

**0:00–1:00 安顿**

口播（进段）：找一个能靠住的地方。舌尖轻轻抵上颚。用嘴把肺里的气全部呼出去，像放掉一个憋了很久的气球。

| 秒 | 对人说 |
|----|--------|
| 25 | 会议室还留在身上的那一点热，交给这一次呼气。 |
| 45 | 下一次我们会数：四、七、八。乱了就从下一次吸气重新开始。 |

**1:00–7:00 4-7-8 循环**

口播（进段）：用鼻子安静吸气，心里数四。屏住，数七。噘起嘴唇，缓缓呼出，数八，发出很轻的「呼」。不需要完美。

| 秒 | 对人说 |
|----|--------|
| 3 | 吸，二，三，四。 |
| 8 | 停……让它停在身体里。 |
| 16 | 呼——把气从嘴角轻轻漏出去。 |
| 40 | 下一次一样。你只跟呼气走。 |
| 之后 | 默数交给画面。 |

自适应（各最多一次）：90 秒后 arousal 仍高于 70 →「呼气再放长一点点。」；若唤醒和专注一起顶高（在较劲）→「不必数得很准，乱了就从下一次吸气开始。」

**7:00–8:00 自然呼吸**

口播（进段）：把数数放下。让呼吸自己流动，你只是看着它。

| 秒 | 对人说 |
|----|--------|
| 30 | 注意心跳。它比一分钟前慢了一点。 |

结束：三角空着，尘几乎没了。不要立刻切下一场的亮色。

### 前端怎么算做对

闭眼靠「聚—停—泄」能感到 4-7-8，泄比聚长。会后高唤醒时尘明显，长呼气后变少。不是开工那套方块。

## 3. 下工仪式 · `clock-out` · `ritual-offwork`

**10 分钟。** 唤醒 down · 专注 keep · 平静 up。

### 为什么是这个方法

心理脱离：人要从工作恢复，得先在脑子里下班，不是人已经离开工位。仪式分两步——把没做完的事封存（认知闭合），再把注意交给生活感官（重锚）。这不是睡前，不要做成瑜伽休息术。

呼吸不当作主任务。背景用约 5 秒吸、7 秒呼，口播不数拍。

### 画面

炭黑场，底部一条钨丝色抽屉。封面那根底栏是第三段才出现的「已经关上」。

| 阶段 | 画面 |
|------|------|
| 盘点封存 | 抽屉开着。短横条（未完事项）一张张落进去。唤醒高：条子更多，盖子合得慢。 |
| 感官换挡 | 盖子合上大半。暖光从抽屉缝漫出来，工作几何往后退。平静高：暖光更满。 |
| 入场 | 抽屉关死，只留底栏一道暖光。场是室内，不是夜空。 |

| 通道 | 映射 |
|------|------|
| arousal | 未落进抽屉的条子数量、盖子开合 |
| calm | 室内暖光铺得多满 |
| focus | 生活侧纹理清不清（保持即可，不要做成盯方块） |

少动：抽屉停在当前开合，条子不掉。

不要用开工的方块或会后的泄光三角。下工是「合上」，不是「画格子」或「把气倒空」。

### 训练怎么走

**0:00–3:00 盘点封存**

口播（进段）：把今天没做完的事在脑子里快速过一遍。对每一件说：我知道你在这儿，明天上午我会处理你。然后想象把它们放进一个抽屉，关上。

| 秒 | 对人说 |
|----|--------|
| 35 | 第一件没做完的。看见它，放进去。 |
| 75 | 下一件。不用排序，也不用解决。 |
| 120 | 抽屉还张着一点。剩下的，也放进去。 |
| 160 | 现在把盖子往下带。不是忘掉，是先收好。 |

自适应：arousal 连续高于 70 →「可以只放三件最吵的。其它的，盖子合上以后就不翻了。」

**3:00–8:00 感官换挡**

口播（进段）：现在把注意力完全交给眼前的生活。如果在做菜，听切菜的声音、闻食材的气味。如果在路上，感受脚步和晚风。工作不在这里，而你在。

| 秒 | 对人说 |
|----|--------|
| 30 | 你的手现在碰到的是什么。 |
| 90 | 空气是凉的还是闷的。只是感觉。 |
| 160 | 远处有什么声音。让它在，不用命名。 |
| 230 | 工作已经在抽屉里。你不用再打开。 |

**8:00–10:00 入场**

口播（进段）：深呼吸一次。对自己说：工作已结束，今晚属于我。从现在开始，你不是角色，你是你自己。

| 秒 | 对人说 |
|----|--------|
| 50 | 盖子已经合上。今晚不用再打开。 |
| 90 | 带着这个身体，去下一件生活里的事。 |

结束：底栏稳住，暖，不闪。不要淡成睡眠星空。

### 前端怎么算做对

能看见「东西进抽屉 → 盖上 → 只剩一条暖边」。高唤醒时盖子合得慢，是可演示的。口播在谈生活，画面在合上工作，两件事对得上。
