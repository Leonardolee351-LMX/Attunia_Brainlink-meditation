# 4-7-8 生理刹车 · 引导文案（超载染色）

- **planId:** `breath-478`
- **场景染色:** 大脑超载 `overload`（尘/残留写成「标签热」，不写会议室）
- **时长:** 8 分钟
- **方法:** 吸 4 · 停 7 · 呼 8；刹车做在加长呼气上
- **替代:** 屏息不适或孕期 → 改 4-0-8（吸 4，直接慢呼 8，中间不停）

---

## 开场（可选）

如果身体比脑子更吵——心口热、呼吸浅——我们先不关窗口。  
先用呼吸，把身上的热，泄出去一点。

---

## 阶段 1 · 安顿（0:00–1:00）

### 进段口播

找一个能靠住的地方。舌尖轻轻抵在上颚。  
现在，用嘴把肺里的气全部呼出去。像放掉一个憋了很久的气球。  
先别管窗口。把身上的热，交给这一次呼气。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:20 | 呼干净。空一点，没关系。 |
| 0:35 | 先别管窗口。把身上的热，交给这一次呼气。 |
| 0:48 | 下面我们数：四、七、八。乱了，就从下一次吸气重新开始。 |

### 4-0-8 替代进段（若启用）

……下面我们数：四，然后直接慢慢呼八拍。中间可以不停。乱了，就从下一次吸气开始。

---

## 阶段 2 · 4-7-8 循环（1:00–7:00）

### 进段口播

用鼻子安静吸气，心里数四。  
屏住，数七。  
噘起嘴唇，缓缓呼出，数八，发出很轻的「呼」。  
不需要完美。你只跟呼气走。

### 带一遍示范（前约 50 秒）

| 时刻 | 文案 |
|------|------|
| 0:03 | 吸，二，三，四。 |
| 0:08 | 停……让它停在身体里。 |
| 0:16 | 呼——把气从嘴角轻轻漏出去。五、六、七、八。 |
| 0:40 | 下一次一样。你只跟呼气走。 |

### 之后

默认静音，把节拍交给画面（聚—停—泄）。约每 90–120 秒可轻声一句，不要每圈都念满：

| 可选时刻 | 文案 |
|----------|------|
| ~2:00 | 呼气，可以再长一点点。 |
| ~4:00 | 标签上的热，跟着呼气往下走。 |
| ~5:30 | 乱了就放下。下一次吸气，再来。 |

### 自适应（各最多一句）

- 约 90 秒后仍很紧：「呼气再放长一点点。」  
- 又紧又在较劲：「不必数得很准。乱了就从下一次吸气开始。」

### 4-0-8 示范短句

| 时刻 | 文案 |
|------|------|
| 0:03 | 吸，二，三，四。 |
| 0:08 | 呼——慢慢放。不用停在中间。 |
| 0:40 | 你只跟呼气走。 |

---

## 阶段 3 · 自然呼吸（7:00–8:00）

### 进段口播

把数数放下。让呼吸自己流动。你只是看着它。  
注意心跳。如果它比一分钟前慢了一点，就让它慢。  
窗口，可以晚一点再开。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:25 | 不用再数。气自己会来。 |
| 0:45 | 心跳如果慢了一点，就让它慢。 |

---

## 收束

可以慢慢睁开眼。  
身上轻了一寸，就够这一轮。
