# 渐进式肌肉放松 · 引导文案（超载染色）

- **planId:** `pmr-release`
- **场景染色:** 大脑超载 `overload`（下工可复用同一套，只改开场一句）
- **时长:** 12 分钟
- **方法:** 雅各布森 PMR——先紧 5 秒，再彻底松开；松开那一下才是练习
- **注意:** 七成力，不憋气；拉伤或术后部位跳过

---

## 开场（可选）

脑子开着很多窗口的时候，身体常常也跟着端着。  
这十二分钟，我们不关窗口。我们只让肌肉，先学会「放下」。

（若在下工场景改用：）  
这是把白天攒在肩膀里的力交出去，不是再练一轮。

---

## 阶段 1 · 安顿（0:00–2:00）

### 进段口播

坐好，或轻轻躺下。双脚踩实，或腿放松地放着。  
这个练习只有一个动作：用力绷紧五秒，然后一下子松掉。  
我们先从手开始。只用七成力。不要憋气。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:30 | 只用七成力。不要憋气。 |
| 1:10 | 等一下我会数五下。松开的那一下，才是练习。 |
| 1:40 | 肩膀可以先不用端着。我们一会儿会轮到它。 |

---

## 阶段 2 · 紧–松循环（2:00–10:00）

### 进段口播

握紧拳头。五、四、三、二、一——松开。感受那股暖流漫开。  
接下来是小臂、肩膀、脸、腹部、腿。一组一组来。  
每一组都只用七成力。绷紧不是目的。松开，才是。

### 按部位口播（阶段内相对秒；约每 70–80 秒换一组）

| 时刻 | 文案 |
|------|------|
| 0:00 | 手。握紧——五、四、三、二、一。松开。让热流散开。 |
| 1:20 | 小臂。同样，七成力。绷紧——五、四、三、二、一。松开。 |
| 2:40 | 肩膀。轻轻往耳朵方向耸一下。五、四、三、二、一。放下来。比刚才低一点。 |
| 4:00 | 脸。轻轻皱一下眉，咬一下牙关——五、四、三、二、一。松开下巴，松开眼睛周围。 |
| 5:20 | 腹部。微微收一下。五、四、三、二、一。交给椅背，或交给床。 |
| 6:40 | 腿。脚尖轻轻绷一下。五、四、三、二、一。像陷进地板。 |
| 7:40 | （若仍有时间）再回到手，做一轮更轻的。松开比刚才更彻底一点。 |

### 自适应（最多一句）

若又紧又用力过头：  
「可以再轻一点。松开比绷紧重要。」

---

## 阶段 3 · 整体沉静（10:00–12:00）

### 进段口播

现在，整条身体都松过一遍了。  
安静地坐着。不用检查松得够不够。  
只是感受：和十二分钟前，有什么不一样。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:40 | 不用评价。差别本身，就够了。 |
| 1:20 | 窗口还在外面。身体，已经先落地了一寸。 |
| 1:50 | 可以慢慢活动一下手指。当你准备好，再睁开眼。 |

---

## 禁忌提示（不要口播给用户，给产品/合规）

- 肌肉拉伤、术后：跳过对应部位  
- 不要憋气、不要十成力
