# 渐进式身体扫描 · 引导文案

- **planId:** `scan-progressive`
- **场景染色:** 下工仪式 `clock-out`（也可午憩）
- **时长:** 15 分钟
- **方法:** 注意逐区走过身体，允许放松；不做紧—松对照（那是 PMR）
- **注意:** 创伤史可跳过侵入性强的句子，改成「注意到那里就离开」

---

## 开场（可选）

这十五分钟，把注意还给身体。  
不用评价紧或不紧。只是走过。

---

## 阶段 1 · 着陆（0:00–2:00）

### 进段口播

躺下，或深深靠进椅背。  
感受身体被支撑着——你不用用力，椅子会接住你。  
做三次比平时更深的呼吸。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:25 | 第一次。把背交给椅子。 |
| 1:00 | 第二次。腿也可以沉。 |
| 1:35 | 第三次。我们从上面开始往下走。 |

---

## 阶段 2 · 分区扫描（2:00–13:00）

### 进段口播

把注意力带到头顶和脸，觉察温度和触感，然后允许它们松下来。  
慢慢向下。每到一个地方，只对那里说：你可以休息了。

### 分秒短句（约每 90 秒一区）

| 时刻 | 文案 |
|------|------|
| 0:00 | 头顶、额头、下颌。 |
| 1:30 | 肩膀。有没有还端着。 |
| 3:00 | 手臂到手指。 |
| 4:30 | 胸口。呼吸从这里经过。 |
| 6:00 | 腹部。不用收。 |
| 7:30 | 大腿到膝盖。 |
| 9:00 | 小腿、脚踝、脚底。 |

### 自适应

某处卡住：「不必等它完全松开。注意到，就可以往下走。」

---

## 阶段 3 · 整体整合（13:00–15:00）

### 进段口播

现在感受整个身体作为一个整体在呼吸。  
不评价任何感觉，来了就看着，走了就让它走。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:50 | 今晚不用再把身体当工具。它已经可以休息了。 |

---

## 收束

身体在这儿。你可以慢慢回来。
