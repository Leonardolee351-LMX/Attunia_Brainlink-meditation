# 大脑超载 · 四模块引导文案

场景 `overload`。四个已有 `planId`，不新增练习。

| 顺序建议 | 模块 | 何时用 | 文案文件 |
|----------|------|--------|----------|
| 1（主） | `grounding-54321` | 脑子开太多窗口、坐不住 | [guidance.md](../grounding-54321/guidance.md) |
| 2 | `pmr-release` | 身体比脑子更紧 | [guidance.md](../pmr-release/guidance.md) |
| 3 | `breath-478` | 心口热、呼吸浅 | [guidance.md](../breath-478/guidance.md) |
| 4 | `imagery-safeplace` | 念头停不下来、需要一个可回的地方 | [guidance.md](../imagery-safeplace/guidance.md) |

口播约定：第二人称、现在时、短句、不评判、不报脑电分数。超载染色用「窗口 / 标签」，不用「会议室」。

机器可读 cue：各目录下 `guidance.json`。回写 `presets.ts` 的 `phases[].instruction` 须总控批准。
