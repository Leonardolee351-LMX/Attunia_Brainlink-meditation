# 大脑超载 · 四模块交互动效（意义匹配）

**目的：** 让画面「在说」与逐字稿同一件事——落地、松、泄、回岛；不是通用光球呼吸。  
**给前端（主入口）：** [`docs/agent-lab/briefs/FRONTEND-HANDOFF-overload-visuals.md`](../../briefs/FRONTEND-HANDOFF-overload-visuals.md)（票 **F-23**）。  
**参考原型：** 同目录 `interactive-demo.html`（编辑器里常打不开，**实现以交接文档为准**）。

---

## 硬规则（四模块共用）

1. **协议钟驱动节奏**（楼梯层数 / 紧-松 5+8 / 4-7-8 / 门洞阶段）。脑电**不**改拍子。
2. **脑电只改品质**：标签密度、场空度、当前层清晰度、门远近暖度。
3. **母题互不抄**：楼梯 ≠ 泄光三角 ≠ 紧松双圆 ≠ 门洞。
4. **超载染色**：黏土 `#FF6B4A` → 鼠尾草；尘/残片是**标签/窗口**，不写会议室。
5. **口播短句出现时，画面必须有对应事件**（亮一级 / 松一大圆 / 泄一段 / 门亮一档）。

## 1. `grounding-54321` · `ground-stairs`

| 口播阶段 | 训练状态（意义） | 画面事件（必须） |
|----------|------------------|------------------|
| 看 · 5 | 注意离开脑子，落到外物 | 第 5 级（最大）点亮；每句「第 N 样」→ 级上亮一个点；背后标签开始少 |
| 触 · 4 | 身体边界回来 | 第 4 级；边变厚（可摸）；「脚底」时级底微沉 |
| 听 · 3 | 场静下来 | 第 3 级变软（圆角/模糊边）；场噪声降 |
| 嗅 · 2 + 长呼 | 收束 + 一次释放 | 第 2→1 级；最后「长呼气」→ 全场缓慢下沉一寸，标签几乎没 |

| 通道 | 品质映射 |
|------|----------|
| arousal | 背后标签残片数量 |
| calm | Sage 地面沉度 |
| focus | 当前级边缘是否清楚 |

**禁止：** 方块画边呼吸、泄光三角、用圆环代替楼梯。

## 2. `pmr-release` · `tense-release-discs`（超载：黏土/沙）

| 口播阶段 | 训练状态 | 画面事件 |
|----------|----------|----------|
| 安顿 0–2′ | 建立「紧→松」预期 | 双圆待命；小圆微颤示意「将要绷」 |
| 每组「握紧 / 五…一」 | 对照：先尝紧 | **小圆 5s 收死**（黏土色） |
| 「松开」 | 对照：松才是练习 | **大圆约 8s 铺开**（沙色），小圆消 |
| 换部位口播 | 注意移到下一组肌群 | 焦点移到下一对圆（或同一对换标签） |
| 整体沉静 | 差别本身够了 | 只留淡沙场，双圆几乎不动 |

协议钟：紧 5 + 松 ≈8 ≈ 一组 13s。七成力视觉：小圆不要抖成警报。

| 通道 | 品质 |
|------|------|
| arousal | 小圆有多「死」 |
| calm | 大圆铺得多满 |
| focus | 当前这一组是否单独点亮 |

**禁止：** 楼梯、方块呼吸、把门洞当放松球。

## 3. `breath-478` · `exhale-triangle`（尘＝黏土标签）

| 口播 / 拍 | 训练状态 | 画面事件 |
|-----------|----------|----------|
| 安顿 · 先呼干净 | 先泄身上的热 | 三角空一下；尘略落 |
| 吸 4 | 聚 | 三角**聚拢**（顶点收） |
| 停 7 | 停在身体里 | 三角**悬停**，几乎不动 |
| 呼 8 | 刹车在呼气 | 三角**泄光向下**，标签尘随泄下降 |
| 自然呼吸 | 放下数数 | 三角极淡脉动，尘少 |

| 通道 | 品质 |
|------|------|
| arousal | 标签尘密度 |
| calm | 泄完后场有多空、多鼠尾草 |
| focus | 泄轨迹是否连贯（不改拍） |

**禁止：** 会议室灰尘文案；用通用圆环冒充 4-7-8。

## 4. `imagery-safeplace` · `safe-portal`

| 口播阶段 | 训练状态 | 画面事件 |
|----------|----------|----------|
| 三次呼气卸背包 | 肩沉、准备进岛 | 左侧门洞从远/虚 → 每呼一次近一点 |
| 定光线 / 空气 / 声 / 脚下 | 五感搭场景（不生图） | 门内色块逐档清晰；**只用几何色场** |
| 「窗口不在这里」 | 切断反刍 | 门外标签残片推到画外 |
| 手在心口 · 回房间 | 锚定可返回 | 门保持可见；场略回房间灰粉 |

| 通道 | 品质 |
|------|------|
| arousal | 门远、发虚 |
| calm | 门近、暖 |
| focus | 门内色块清不清 |

**禁止：** 现场生成风景图、把楼梯/三角塞进门洞。

## 验收（演示页 / 真机共用）

- [ ] 关掉字幕也能猜出在练哪一种（楼梯 / 紧松 / 泄三角 / 门）。
- [ ] 拖高 arousal 只变「挤/远/尘多」，**节拍不变**。
- [ ] 口播关键短句（第一样、松开、呼——、门在左边）有画面事件。
- [ ] 超载四套母题互不复用。

前端接线建议：`visual.kind` ∈ `ground-stairs | tense-release-discs | exhale-triangle | safe-portal`；`cues` 用各模块 `guidance.json`。
