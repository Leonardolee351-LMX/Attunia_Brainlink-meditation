# 感官着陆 5-4-3-2-1 · 引导文案

- **planId:** `grounding-54321`
- **场景染色:** 大脑超载 `overload`
- **时长:** 5 分钟
- **方法:** 临床 grounding——用外部感官输入打断反刍，一层层把注意拉回此时此地

---

## 开场（进练习前，可选 10 秒）

这五分钟，我们不处理任何一个窗口。  
只做一件事：让眼睛、手、耳朵、鼻子，把你带回这张椅子上。

---

## 阶段 1 · 看 · 5 样东西（0:00–1:00）

### 进段口播（TTS 主句）

环顾四周。在心里，慢慢说出你看到的五样东西。  
不用特别。桌角、水杯、光斑、一根线，都可以。  
一样一样来。看见它，再看下一个。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:12 | 第一样。看见它。 |
| 0:24 | 第二样。 |
| 0:36 | 第三样。不用挑好看的。 |
| 0:48 | 第四样。 |
| 0:56 | 第五样。它们都在这儿。你也在这儿。 |

### 静默

短句之间留空，让人自己点名。不要催。

---

## 阶段 2 · 触 · 4 种触感（1:00–2:00）

### 进段口播

现在，找到四种触感。  
衣料贴着皮肤的质地。桌面或扶手的凉。脚底踩着的支撑。自己手心的温度。  
每种，停几秒。只是感觉，不用形容得很漂亮。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:10 | 衣料。指尖碰一碰也行。 |
| 0:25 | 桌面，或椅子的扶手。 |
| 0:40 | 脚底。你踩着的地方，接住你。 |
| 0:52 | 手心。热的或凉的，都算。 |

---

## 阶段 3 · 听 · 3 种声音（2:00–3:00）

### 进段口播

可以轻轻闭上眼。  
找出周围三种声音。远处的也算。自己的呼吸也算。  
只是听。不用评价吵或不吵。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:12 | 第一种声音。 |
| 0:32 | 再远一点的。 |
| 0:50 | 呼吸，也可以是第三种。 |

---

## 阶段 4 · 嗅 · 2 + 一口长呼气（3:00–5:00）

### 进段口播

留意两种气味。很淡也行。没有的话，回想一种你熟悉的气味，也可以。  
然后，只做一次——又慢又长的呼气。  
你已经回到此时此地了。标签，可以先关上。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:20 | 第一种气味。哪怕几乎没有。 |
| 0:50 | 第二种。记忆里的，也算。 |
| 1:20 | 现在，只做一次很长的呼气。把气慢慢放完。 |
| 1:40 | 标签可以先关上。你在这张椅子上。 |
| 1:55 | 五个窗口，我们一个都没开。这样就够了。 |

### 自适应（本阶段最多一句）

若仍很紧、坐不住：  
「可以只做看到的三样，和脚底。够了。」

---

## 收束（可并入最后 5 秒）

慢慢睁开眼，如果还闭着。  
外面的事还在。你先落地了。
