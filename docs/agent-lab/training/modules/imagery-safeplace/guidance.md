# 安全岛引导意象 · 引导文案（超载染色）

- **planId:** `imagery-safeplace`
- **场景染色:** 大脑超载 `overload`
- **时长:** 12 分钟
- **方法:** 用五感搭建一个可返回的安全场景，切断反刍；不是再想解决方案
- **注意:** 急性惊恐先做着陆或 4-7-8；解离倾向慎用，可改回 5-4-3-2-1
- **画面约束:** 只用「门洞」几何，不现场生风景图

---

## 开场（可选）

有时候窗口关不上，是因为脑子还在演「没做完的事」。  
这十二分钟，我们不解决问题。  
我们只去一个地方——只有你能进的地方。

---

## 阶段 1 · 放松诱导（0:00–3:00）

### 进段口播

闭上眼睛。跟三次深呼吸走。  
每次呼气，想象肩膀往下沉一点点。像卸下一个很重的背包。  
门，会在左边等你。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:20 | 第一次呼气。背包带，松一扣。 |
| 1:10 | 第二次。肩再低一点。 |
| 2:00 | 第三次。把脸上的用力，也呼出去。 |
| 2:30 | 门会在左边等你。你不用跑。慢慢走过去就行。 |

---

## 阶段 2 · 场景建构（3:00–10:00）

### 进段口播

想象一个让你感到绝对安全的地方。  
可以是真实去过的，也可以是完全虚构的。  
那里的光线是什么颜色？空气是什么温度？远处有什么声音？  
用眼睛、皮肤、耳朵，把它搭得清楚一点。  
这个地方只属于你。没有任何人可以进来。窗口，不在这里。

### 分秒短句（引导五感，中间多留静默）

| 时刻 | 文案 |
|------|------|
| 0:30 | 先定光线。亮一点，或暗一点，都可以。 |
| 1:30 | 空气是凉的，还是暖的。让皮肤告诉你。 |
| 2:40 | 远处有没有一种声音。很远也行。让它在。 |
| 3:50 | 脚下踩着什么。土地、地板、沙子，或别的。 |
| 5:00 | 如果有一个气味，很淡，也可以留下。 |
| 6:00 | 没有人能进来。窗口不在这里。你只是待着。 |
| 6:40 | （静默为主）若念头又来：看见它，不要跟走。回到光线，或脚下。 |

### 自适应（最多一句）

若待不住、画面搭不起来：  
「不必把地方想完整。有一扇门，就够待一会儿。」

---

## 阶段 3 · 锚定返回（10:00–12:00）

### 进段口播

把右手轻轻放在心口。记住这个感觉。  
以后任何时候，只要做这个手势，你可以在几秒钟内回到这里。  
现在，慢慢回到房间。门还在。房间也还在。  
你可以晚一点，再开那些窗口。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:35 | 手在心口。门还在。 |
| 1:10 | 动一动手指。脚尖。 |
| 1:40 | 睁开眼。房间还在。你可以晚一点再开窗口。 |

---

## 收束

安全岛不是逃避。  
它是你给自己留的一寸空，好让神经系统先落地。
