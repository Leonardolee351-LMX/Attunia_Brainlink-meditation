# 晨间唤醒序列 · 引导文案

- **planId:** `morning-prime`
- **场景染色:** 可与晨光音景 / 开工搭配
- **时长:** 6 分钟
- **方法:** 轻度伸展换气 + 节律充能，温和切到上线模式
- **注意:** 高血压或眩晕史跳过快速呼吸段

---

## 开场（可选）

起床后六分钟。  
温和地把大脑从睡眠模式，切到上线模式。

---

## 阶段 1 · 苏醒呼吸（0:00–2:00）

### 进段口播

坐起来，双脚落地。  
吸气时把手臂向上伸展，呼气时放下。  
配合呼吸做八次，动作可以慢一点。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:15 | 吸——手臂向上。 |
| 0:30 | 呼——放下。 |
| 0:50 | 再来。慢一点也行。 |
| 1:30 | 第八次。脚踩实。 |

---

## 阶段 2 · 节律充能（2:00–5:00）

### 进段口播

做二十次稍快的鼻吸鼻呼（大约每秒一次），然后自然呼吸一分钟。  
注意力放在身体逐渐发热的感觉上。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:10 | 鼻吸鼻呼。轻松一点。 |
| 0:40 | 继续。感觉身体在醒。 |
| 1:10 | 可以停。改成自然呼吸。 |
| 2:00 | 感受发热。不用再加快。 |

### 跳过快速段时

「跳过快速呼吸。只做几次深长的吸呼，感受手脚慢慢暖起来。」

---

## 阶段 3 · 定个调（5:00–6:00）

### 进段口播

睁眼之前，想一件今天值得期待的小事——  
哪怕只是一杯好喝的咖啡。带着它开始今天。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:30 | 那件小事，定好了。 |
| 0:50 | 睁眼。今天开始。 |

---

## 收束

带着那件小事，上线。
