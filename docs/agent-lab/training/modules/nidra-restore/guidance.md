# 瑜伽休息术 NSDR · 引导文案

- **planId:** `nidra-restore`
- **场景染色:** 午憩航道 `lunch-tide`（常用）
- **时长:** 20 分钟
- **方法:** 非睡眠深度休息——在清醒与睡眠边界系统性恢复
- **注意:** 严重缺睡可能睡着，可设轻柔闹钟

---

## 开场（可选）

不需要睡着，也可以像睡了一觉。  
这二十分钟，给透支的系统一次维护。

---

## 阶段 1 · 意向设定（0:00–2:00）

### 进段口播

躺好，比平时更慢一点地安顿身体。  
在心里对自己说一句话，作为这次练习的意向——  
比如：「我允许自己休息。」

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:30 | 后脑、肩、腿，交给支撑你的地方。 |
| 1:20 | 那句意向，再说一次。轻一点。 |

---

## 阶段 2 · 身体与呼吸觉察（2:00–8:00）

### 进段口播

快速扫描全身：哪里还有用力？找到它，呼气时把它交给地面。  
然后只是数呼吸，从十倒数到一。数乱了，就从十再来。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:40 | 哪里还在用力？呼气，交给地面。 |
| 2:00 | 开始数呼吸。十。 |
| 3:00 | 九……八……不用完美。 |
| 4:30 | 乱了就从十再来。 |

---

## 阶段 3 · 对立感觉练习（8:00–16:00）

### 进段口播

现在玩一个游戏：先感觉身体很重，像陷进地面……  
再感觉很轻，像要浮起来。  
重——轻——暖——凉。  
你的神经系统正在学习灵活切换，这就是恢复本身。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 0:30 | 整个人很重。像陷进去。 |
| 2:00 | 现在很轻。像要浮起来。 |
| 3:30 | 暖……再凉一点。 |
| 5:00 | 重，再轻。切换本身，就是练习。 |
| 6:30 | 不用选哪一个更好。只是换。 |

---

## 阶段 4 · 意象与整合（16:00–20:00）

### 进段口播

让任何画面自然地来，不挑选、不跟随。  
最后，把意识慢慢带回房间：动动手指、脚趾。  
带着这份余量，回到你的下午。

### 分秒短句

| 时刻 | 文案 |
|------|------|
| 1:00 | 画面来了就看着。走了就让它走。 |
| 2:30 | 动一动手指。脚趾。 |
| 3:20 | 带着余量，慢慢回来。 |

---

## 收束

余量带走。下午还可以用。
