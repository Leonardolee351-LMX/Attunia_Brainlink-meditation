# Attunia（Brainlink Meditation）

Attunia 是面向脑电冥想训练的产品原型：会话、场景、与 Agent **Tuno** 对话，以及 Multi-Agent 会诊编排。

本地开发工作区目录名可能仍为 `NeuroFlow-AgentLab`；产品对外名称统一为 **Attunia**。

## 快速开始

```bash
npm install
npm run dev
```

密钥与环境变量放在本机 `.env`（已 gitignore），不要提交。

## 仓库说明

- 前端：`src/`
- 后端：`api/`、`db/`
- 共享契约：`contracts/`
- Agent 协作协议：`AGENTS.md`、`docs/agent-lab/`
