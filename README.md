# Attunia（Brainlink Meditation）

Attunia 是面向脑电冥想与身心状态调节的产品原型：佩戴设备校准基线、按生活场景做短训、与 Agent **Tuno** 对话，以及 Multi-Agent 会诊（从已有疗法目录按环节拼装，不即兴创作）。

本地开发目录名可能仍为 `NeuroFlow-AgentLab`；**产品对外名称统一为 Attunia**。对话 Agent 名为 **Tuno**。

> Attunia 提供的是冥想与身心状态调节练习，不构成医疗诊断、治疗或处方建议。

## 快速开始

```bash
npm install
npm run dev
```

密钥与环境变量放在本机 `.env`（已 gitignore），不要提交。奇绩 / MiniMax 等本地配置见 `config/*.md` 与 `.cursor/settings.local.json.example`。

## 仓库结构

| 路径 | 说明 |
|------|------|
| `src/` | 前端（开屏 / 首页 / 会话 / 场景 / Chat / 会诊） |
| `api/` `db/` | 后端与数据；产品 Agent 对话设计现阶段归后端 |

会诊现行边界：`docs/agent-lab/multi-agent-boundary.md`（按目录拼环节，不生图、不作曲、不发明新练习）。

## Todo（产品待办）

### 1. 脑电波主动交互提醒（Backend）

在用户**已佩戴设备**的前提下，程序需要**主动**识别并判定「此刻更需要休息 / 更需要专注」的瞬间，再触发合适提醒或短训入口——而不是只等用户点开 App。

**归属：** 后端主导（判定逻辑、阈值、冷静期、与会话/场景的衔接）；前端只渲染提醒与跳转。

**待想清楚的触发条件（草案，实现前由后端落成规格）：**

- 信号前提：佩戴可靠、信号质量达标；基线已校准或有可用个人基线
- 「需要休息」候选：持续高负荷 / 高 distraction、恢复指标偏低、相对基线显著偏离且持续一段时间
- 「需要专注」候选：该时段本应专注但指标飘散、或用户刚从休息态回到任务却尚未进入专注带
- 防打扰：最小间隔、每日上限、勿扰时段、用户刚完成训练后的冷却
- 合规：提示文案保持「状态调节 / 练习建议」语气，不做医疗断言；原始脑电不送入外部 LLM

### 2. 训练过程交互动效（Frontend + 训练咨询）

训练中不只是「看动画」，而要有**可玩的元素交互**：触达、节奏跟练、反馈回路，带一点游戏性与玩法清晰度。

**归属：** 训练咨询写厚玩法与引导意图；前端落地动效与手势；物料仍用已有疗法 / 场景目录，不另起炉灶生图作曲。

**待补充的设计面：**

- 元素怎么「可交互」（点按、长按、跟随呼吸相位、滑动轨迹等）
- 成功 / 漂移 / 结束时的反馈（视觉 + 轻量音效，沿用场景物料）
- 玩法目标一句话能说清（例如：把涟漪稳住 N 次、跟随花瓣开合完成一组）
- 与脑电或会话进度的挂钩方式（可选：状态好时反馈更柔和 / 更清晰，仍非医疗评分）
